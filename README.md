# رحلة في عالم الضاد
موقع تعليمي تفاعلي: الفعل اللازم والفعل المتعدي (الصف الأول الإعدادي). HTML/CSS/JS فقط.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر المستودع (يجب أن يكون `index.html` في الجذر).
2. Settings ← Pages ← Source: Deploy from a branch ← `main` / `(root)`.
3. افتح الرابط: `https://USERNAME.github.io/REPO/`
